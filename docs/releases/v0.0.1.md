# Eglantine-Framer v0.0.1 — Notas del parche

**Primera versión experimental del fork, enfocada en las pruebas de Pokémon Pokopia.**
Esta versión se basa en Eglantine `nx2`. Las correcciones heredadas del proyecto original no se presentan como si fueran cambios nuevos de este fork.

## Cambios del fork

### Emulación y gráficos

- **Vulkan — vistas de búferes de textura nulos:** se utiliza `VK_WHOLE_SIZE` en lugar de un tamaño cero, para crear una vista válida cuando se emplea el búfer de reserva.
- **Vulkan — compatibilidad del búfer de reserva:** se incluyen los usos `VK_BUFFER_USAGE_UNIFORM_TEXEL_BUFFER_BIT` y `VK_BUFFER_USAGE_STORAGE_TEXEL_BUFFER_BIT` para que ese búfer pueda respaldar descriptores de texturas de búfer. ([PR #1](https://github.com/Framerr/Eglantine-Framer/pull/1))

### Versiones, compilación y mantenimiento

- Se establece la versión propia **0.0.1** y un historial de cambios para el fork. ([PR #2](https://github.com/Framerr/Eglantine-Framer/pull/2))
- Se añade la opción de lanzar manualmente una publicación estable desde el workflow `ci`. ([PR #3](https://github.com/Framerr/Eglantine-Framer/pull/3))
- Se incorpora `fork-preflight` para comprobar en cada PR y cambio a `nx2` la versión, las notas y la sintaxis de los scripts de CI. ([PR #5](https://github.com/Framerr/Eglantine-Framer/pull/5))
- Se añade `fork-windows-release` para compilar y publicar versiones de prueba para Windows aprovechando los workflows de Eglantine. ([PR #6](https://github.com/Framerr/Eglantine-Framer/pull/6))
- Se elimina el workflow heredado `Retarget PRs`, que fallaba porque esperaba una rama `nx2-experimental` inexistente en este fork.

### Organización de las pruebas

- Nueva [guía de pruebas de Pokémon Pokopia](https://github.com/Framerr/Eglantine-Framer/blob/nx2/docs/POKOPIA_TESTING.md), con casos de arranque, carga de partidas, geometría, iluminación, fotos, sonido, guardado y rendimiento.
- Nuevo formulario específico para informar de errores de Pokopia, más información del proyecto en el README y documentación de CI actualizada. ([PR #4](https://github.com/Framerr/Eglantine-Framer/pull/4))
- **Aviso:** para utilizar los formularios es necesario que la función *Issues* esté activada en la configuración del repositorio.

## Resumen sin tecnicismos

Esta es **la primera versión para empezar a probar el juego en tu fork**. Hemos corregido una forma incorrecta de gestionar ciertos recursos gráficos vacíos, que podía causar problemas en determinadas situaciones. También hemos preparado el repositorio para crear versiones de Windows, detectar fallos antes de integrar cambios y recoger los resultados de las pruebas.

**Lo que todavía no podemos asegurar:** que Pokémon Pokopia arranque mejor, que se hayan arreglado los objetos invisibles, las fotos con artefactos, los fallos de iluminación o el rendimiento. Son objetivos para próximas versiones, pero primero necesitamos pruebas reales con esta compilación.

Si encuentras un fallo, indica cómo reproducirlo, la versión que estás utilizando y, si es posible, adjunta el registro del emulador (revisando antes los datos personales).
