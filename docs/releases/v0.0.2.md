# Frameropia v0.0.2 — Patch Notes

**First fully rebranded Frameropia test build for Windows.** This version builds on v0.0.1 and the Eglantine `nx2` source, with the changes specific to this fork listed below.

## Changes in this fork

### Application branding

- Rename the visible emulator application to **Frameropia** throughout the main window, Help menu, About dialog, settings pages, game boot windows, shortcuts and error messages.
- Rename Windows binaries to `frameropia.exe` and `frameropia-cli.exe`.
- Update Linux desktop/AppStream metadata, macOS app bundle display name, Windows installer metadata and Arch packaging to match the Frameropia name.
- Route the fork's own project, help, source code, release and issue-reporting links to [Framerr/Frameropia](https://github.com/Framerr/Frameropia); preserve links to third-party dependencies and upstream credits.
- Remove Discord links and the Discord presence option from the user interface, and disable Discord presence even for old configurations.

### Build and release reliability

- Fix the CMake parent-level executable-name override that was still generating `eden-cli.exe` after the frontend had been renamed.
- Fix release packaging to create **one complete Windows ZIP** with both binaries, required DLLs and Qt plugins rather than separate plugin-folder ZIP files.
- Check the packaged filenames before allowing a release to publish.
- Repair the historical `v0.0.1` release by restoring a complete Windows archive from its original successful build; keep its tag and original code intact.
- Keep preflight checks and dedicated Windows build validation for subsequent changes.

### Compatibility and project organization

- Preserve pre-existing Eden/Eglantine configuration, cache and save directories to avoid accidentally separating the user from their settings and saved games.
- Continue maintaining the [Pokémon Pokopia testing checklist](https://github.com/Framerr/Frameropia/blob/nx2/docs/POKOPIA_TESTING.md) and [bug-report form](https://github.com/Framerr/Frameropia/issues/new/choose).

## Plain-English summary

**Frameropia now has its own name inside the program, not just on GitHub.** The main improvement here is consistency: the emulator, its executable files, menus and download archive should all use the Frameropia name. We also corrected the release system so you receive the whole application in one usable ZIP.

Your existing settings and saved games should continue to use the same folders as before. **This update does not claim to fix Pokopia's graphical issues, crashes, missing objects or performance.** Those still require practical testing, and you can report the results using GitHub Issues.

Extract the **entire** Windows ZIP before running `frameropia.exe`. Do not upload game content, keys or firmware with your bug reports.
